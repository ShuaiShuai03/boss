# 求职工作台 UI 升级

## 设计依据

使用 `design-taste-frontend` 的 app-screen 工作流与现有 Nuxt UI 4 组件体系。
抽取方向：True-black flat，seed `1792110053`。没有重抽。
采用黑色地面、灰阶层级、白色主操作；原有 Boss 标志保留。平台页面本身不重绘。
本产品的签名元素是实际批次进度及逐岗位结果，不加入虚构统计、营销图片或占位图。
字体使用本地系统中文字体，避免扩展向字体服务发送访问请求；这是相对于方向表 Inter 字体的明确偏离。

| 屏幕   | 首要问题                                         |
| ------ | ------------------------------------------------ |
| 控制台 | 当前批次进展如何，能否开始或恢复？               |
| 规则   | 哪些岗位会被排除，当前配置是否保存？             |
| AI     | 哪些能力启用、基于哪些个人证据、请求预算是多少？ |
| 日志   | 哪个岗位失败，原因是什么？                       |
| 对话   | 草稿属于哪个招聘者、是否仍需要确认？             |

## 改动

- 明确的产品 h1、可读的中文导航与主题操作；保留键盘漫游标签、帮助模式与现有表单行为。
- 全局灰阶主题替换原有海军蓝/琥珀装饰，去掉静态阴影、渐变警示条及背景模糊。
- 数字采用 tabular figures；辅助文字提高到可读尺寸，避免大范围等宽及字距装饰。
- AI 配置从并排卡片变为横向设置行，小屏幕顺序堆叠，增加个人证据、资料版本、预算、会话事实及岗位准备入口。
- 去掉屏幕进入动画，避免切换时内容暂时不可见。交互保留焦点、禁用及反馈状态。
- 去掉内容容器固定最小高度，空日志界面不再人为撑出大面积空白。
- 小屏幕导航换行、设置字段收敛到单列。岗位卡片评分使用有数值的边框标记。

## 图片复核

首轮发现并修复三项：规则页进入动画导致截图低透明度；空列表固定高度形成空白；手机主题按钮被挤窄。
最终检查覆盖五个标签的三个宽度；五个屏幕均不产生页面水平溢出，外壳宽度分别为 1408、736、358px，即两侧各 16px。
当前版本不含新外部图片、影片或样例用户数据。旧版赞赏图片保留，fixture 中企业头像缺失仅属于测试数据。
资料证据与会话事实须由用户填写；空状态不伪造已保存资料。

### 最后一轮 app-screen 复核

1. 主操作与真实批次进度首先可见；AI 页按模型、能力、证据排列。
2. 外壳左右各 16px，空日志不再被固定高度撑开；AI 全文较长，使用纵向浏览。
3. 导航与主按钮用中性色，颜色集中于成功、失败等状态。保留 Boss 标志。
4. 数字来自现有统计状态；UI 不新增独立计数或推算收益。
5. 零值保留 0，模型未配置、日志为空和资料未保存均有明确文字。
6. 无新增图表或独立图例，原批次进度保留数值与语义 progressbar。
7. 手机页保留短标签导航与顺序设置表单，没有页面级水平滚动。

剩余设计限制：AI 证据表单较长；原有关于页支持图片保留；不通过外网加载字体。
这些不是功能完成声明，运行结果以仓库测试输出为准。
